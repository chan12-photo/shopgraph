- 이 파일은 W12 시연 테스트(tests/test_demo.py)의 **유일한** 기대값 출처다 (11.3.2 W12). 실행 결과를 옮겨 적지 않는다.
- 입력 절차와 장면 순서는 docs/verification/w11_scenes.md를 따른다. 장면 1~8은 `python main.py` 한 번 실행 안에서 처음 상태(data.py)부터 차례로 진행하므로, 각 장면의 값은 **그 앞 장면까지 진행한 상태**로 계산한다.
- 손계산 원자료: docs/verification/w11_raw_by_group.md (data.py 구매 기록을 그룹 → 고객 → 상품 순으로 다시 배열한 표)
- **승인 줄**: 손계산·AI 독립 계산 대조·11.3.8 승인을 마치면 맨 위 상태 줄을 정확히 `상태: 승인 (찬일, YYYY-MM-DD) / AI 독립 계산 대조: 일치`로 바꾼다. tests/test_demo.py는 이 줄일 때만 장면을 실행하고, 그 밖이면 칸이 다 채워져 있어도 "11.3.8 승인 전"으로 멈춘다 (찬일 11/02 판정)

## 쓰는 법

- 칸이 비어 있으면 "아직 채우지 않음"이다. 테스트는 필요한 칸이 하나라도 비어 있으면 NotImplementedError("W11 기대값 승인 전")로 멈춘다.
- 해당 없는 행은 순위 칸 말고 모든 칸에 `-`를 쓴다 (예: 추천 결과가 K개보다 적을 때 남는 순위 행, S4 표에서 남는 행). 해당 없는 행은 쓰인 행 뒤에만 둔다. S4 표 행이 모자라면 같은 모양으로 추가한다 (순위는 1부터 연속). 추천 표는 행이 정확히 3개다
- `-`는 해당 없는 행과 추천 표의 "색상 수 안내" 칸에만 쓸 수 있다. 그 밖의 칸(안내 줄 포함)에 `-`를 쓰면 테스트가 실행 전에 멈춘다
- 열 이름·순서와 행 이름은 바꾸지 않는다. 같은 이름의 장·표·행을 두 번 쓰지 않는다 (테스트가 실행 전에 멈춘다)
- 형식: 고객 ID `C01`, 상품 ID `P01`, 그룹 ID `G-F-20` 모양, 날짜는 실제 날짜 `YYYY-MM-DD`, 점수·구매자 수·가중치·기록 수·총수량·구매 고객 수는 1 이상 정수, 인원·통계 개수·위반 수는 0 이상 정수
- 추천 표 "색상 수 안내": 근거 줄 괄호 안의 색상 수 안내를 그대로 (예: `C02는 2가지`, 여러 명이면 `C10은 2가지, C12는 2가지`, 2가지 이상 산 지지자가 없으면 `-`). 조사는 화면 규칙(ID 끝 숫자 소리)대로
- 범위는 화면 표시 그대로: `같은 그룹` / `여성 전체` / `남성 전체` / `전체 고객`
- 여러 값은 쉼표와 공백으로: 지지자 `C04, C05`, 색상 `베이지, 블랙` (ID 순, 색상 이름순)
- 안내 줄 칸은 `있음` 또는 `없음`
- 숫자는 숫자만 (단위 없이)
