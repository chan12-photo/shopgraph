## 실행 방법

### 준비

- Python 3.11 이상만 있으면 된다. 외부 패키지를 설치하지 않는다 (표준 라이브러리만 사용).
- 저장소 루트에서 실행한다.

### 프로그램 실행

```bash
python main.py
```

- 시작할 때 data.py의 시연 데이터(고객 30명, 상품 22개, 구매 기록 122건)를 읽는다.
- `[0]`을 고르거나, 입력을 끝내거나(Ctrl+D), Ctrl+C를 누르면 "종료합니다"를 출력하고 끝난다.

### 테스트 실행

```bash
python -m unittest -v
```

- tests/의 테스트는 tests/fixtures.py의 고정 데이터(계획서 6.1)를 쓴다. data.py를 읽는 것은 시연 테스트(tests/test_demo.py)뿐이다.
- 시연 테스트는 docs/demo_expected.md(사람이 손계산·승인한 기대값)를 읽고, 기대값이 비어 있는 동안에는 NotImplementedError로 멈춘다.

데이터 점검(개발용):

```bash
python tools/check_data.py
```

### 메뉴 한눈에

```text
[1] CREATE      고객 / 상품 / 구매
[2] READ        조회(ID·이름·조건) / 검색 S1~S4
[3] UPDATE      고객 / 상품 / 구매
[4] DELETE      고객 / 상품 / 구매
[5] PRINT       그룹별 고객 / 상품 목록 / 인접 리스트 / 통계·무결성 검사
[6] RECOMMEND   고객별 추천
[0] Exit
```

| 메뉴 | 하위 기능 |
|---|---|
| [1] CREATE | 고객 등록(등록 직후 추천), 상품 등록, 구매 등록 |
| [2] READ | ID 조회, 이름 조회, 조건 조회, S1 고객이 산 상품, S2 상품을 산 고객, S3 그룹 소속 고객, S4 그룹 인기 상품 |
| [3] UPDATE | 고객 수정, 상품 수정(재고는 통째로 교체), 구매 수정(색상·수량) |
| [4] DELETE | 고객 삭제·상품 삭제(구매 기록 N건 함께 삭제 확인), 구매 삭제 |
| [5] PRINT | 그룹별 고객, 상품 목록, 인접 리스트(노드 하나 또는 전체), 통계·무결성 검사 |
| [6] RECOMMEND | 고객 ID와 K(기본 3)로 추천 |

입력 규칙: 성별·종류·스타일·그룹은 번호로 고른다. 재고는 `블랙=5, 화이트=3`처럼 입력한다. 수정·조건 조회에서 Enter는 "그대로"·"조건 없음"이다.

### 화면 예시

추천 화면 (계획서 5.3.3 출력 예시, 6.1 PoC 데이터의 C06, K=3):

```text
[추천] 고객6(C06, 남성·10대)님께 추천 (3개)
 1. 오버핏 티셔츠 (P01) - 점수 1, 구매 고객 1명 [남성 전체]
    근거: C04(남성·20대)가 구매
    구매 가능 색상: 그레이, 네이비, 블랙, 화이트
 2. 카고 팬츠 (P04) - 점수 1, 구매 고객 1명 [남성 전체]
    근거: C04(남성·20대)가 구매
    구매 가능 색상: 블랙, 카키
 3. 와이드 슬랙스 (P02) - 점수 3, 구매 고객 2명 [전체 고객]
    근거: C01, C02가 구매 (C02는 2가지 색상 구매)
    구매 가능 색상: 베이지, 블랙
 ※ 같은 그룹(남성·10대)에 다른 고객이 없어 '남성 전체'로, 그래도 3개가 안 돼 '전체 고객'으로 넓혀 찾음
 ※ 점수는 각 범위 안에서 계산한 값이라 범위가 다른 항목끼리 비교하지 않습니다
```

고객 삭제 확인 (6.1 PoC 데이터의 C02):

```text
고객2(C02) 삭제: 구매 기록 3건도 함께 삭제됩니다. 계속할까요? (y/n): y
[삭제] 고객2(C02), 구매 기록 3건 함께 삭제
```

잘못된 입력은 메시지를 보여 주고 메뉴로 돌아간다:

```text
[오류] 나이: 10~99이어야 합니다 (입력: 5)
[오류] 성별: 1(남) 또는 2(여)로 입력해 주세요
```
