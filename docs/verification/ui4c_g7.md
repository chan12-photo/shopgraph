# UI4c 기록

- 찬일 UI5 착수 전 지시 0번, 2026-11-03. 자체 확인: Codex(독립 검토 아님).
- 그룹 좌표는 서버 이웃 고객들의 y 좌표 평균으로 옮긴다. 빈 그룹만 남은 좌표에 서버 순서로 배치한다. 원본 노드/그룹/추천 배열을 정렬하지 않는다.
- 기본 글자는 SVG 13 좌표(1440×900에서 12px 이상), 마우스 올림·선택 노드는 17 좌표로 확대한다.
- 선택 정보는 이웃의 서버 이름에 소속 그룹/소속 고객/구매 관계를 붙이고, 구매 간선은 응답 weight를 그대로 표시한다.
- 추천 카드의 근거 줄만 trimStart()로 앞 공백을 지운다. 접힌 콘솔 원문과 Python 콘솔 출력은 유지한다.
- UI5 장면 1을 실제 그래프 화면에서 대조할 수 있도록 그룹 이름 옆에 `/api/groups`의 count도 그대로 표시한다.
- 공개 API·계산·기존 테스트 기대값·패키지/lock 변경 없음. UI5 테스트는 이 커밋 다음에 추가한다.
