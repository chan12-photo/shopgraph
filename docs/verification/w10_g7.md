10. 통계·무결성: `[그래프 통계]` + 표(그룹 노드·고객 노드·상품 노드·소속 간선·구매 간선·구매 기록), `[무결성 검사] 위반 없음 (원본과 그래프가 정한 불변 조건대로 일치)` 또는 `[무결성 검사] 위반 N건` + `  - 위반 설명`
11. 종료: [0]이면 `종료합니다`, EOF·Ctrl+C면 빈 줄 하나 뒤 `종료합니다` (W8b는 EOF에 빈 줄만 찍었음)
12. 입력 변환: ID·구매일·메뉴 번호 입력은 앞뒤 공백을 main.py가 지움. 이름·상품명·색상명은 그대로 넘기고 graph.py가 지움(B.3). 수정·조건 조회에서 공백뿐인 입력은 "그대로"·"조건 없음"
