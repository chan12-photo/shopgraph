## 바꾼 것

- graph.py `_value_error(label, rule, value)`: label이 None이면 "규칙 (입력: 값)", 아니면 "항목: 규칙 (입력: 값)"
- search.py `_value_error(label, rule, value)`: "항목: 규칙 (입력: 값)"
- 값을 repr로 보일지(따옴표)는 바꾸기 전과 같게 부르는 쪽이 정함
- search.py 항목 이름: group_popular "k" → "개수", recommend "k" → "추천 개수 K" (main.py 입력 안내와 같음)
