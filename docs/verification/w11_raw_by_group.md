# 손계산용 원자료표 (data.py 시연 데이터, 그룹 → 고객 → 상품 순)

- 만든 방법: `python docs/verification/make_raw_by_group.py` (data.py만 읽음, graph·search import 없음)
- data.py의 구매 기록을 그룹 → 고객 → 상품 순으로 다시 배열한 것이다. 집계(색상 가짓수·가중치·점수·합계)는 하지 않았다. 손계산은 이 표의 원래 행으로 한다
- 그룹 판정은 계획서 5.2 (성별 + 나이 10~19/20~29/30~39/40 이상)
