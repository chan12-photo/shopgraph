## [제안 형식] (찬일 승인 대상)

1. print_table: 열 사이 공백 2칸, 머리 줄 아래 열 폭만큼 "-", 정수(bool 제외)만 있는 열은 머리까지 오른쪽 정렬, 나머지 왼쪽 정렬, 줄 끝 공백 없음, 행이 없으면 머리·구분 줄만
2. print_table: east_asian_width W·F는 2칸, 그 밖(모호 A인 '·'·'※' 포함)은 1칸
3. print_group_tree: 머리 줄 `[그룹별 고객] 전체 N명`, 성별 줄 `  여성 N명`, 연령대 줄 `    20대 (G-F-20) N명`, 고객 줄 `      C01 고객1 (23세)`. 빈 그룹도 0명으로 표시
4. print_neighbors: 머리 줄 `[인접 리스트] ID 표시 이름 (이웃 N개)`, 이웃 줄 `  ID 표시 이름 (소속)` 또는 `(구매, 가중치 W)`. W는 g.weight() 그대로(상한 적용 전). 이웃이 없으면 머리 줄만

## 계약 빈칸

1. print_table의 예외: B.2 view 행은 "print만, None 반환"만 정함. 칸 수가 맞지 않는 행이면 아무것도 출력하지 않고 ValueError로 제안
2. 모호 폭(A) 문자의 폭: 5.5는 east_asian_width를 쓴다고만 정함. 1칸으로 제안 (한국어 macOS 터미널 기본 설정 기준, 터미널 설정에 따라 2칸으로 보일 수 있음)
3. "인접 리스트: 노드 하나 또는 전체"(5.3.1) 중 "전체"는 view 함수가 없음 → main.py가 GROUP_IDS·customer_ids()·product_ids() 순으로 print_neighbors를 부르는 것으로 제안 (W10)
