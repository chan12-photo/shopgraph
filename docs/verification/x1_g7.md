## 무엇을 바꿨는가

1. 고객·상품은 최소 두 자리, 구매는 최소 세 자리로 발급하되 C99→C100·P99→P100·T999→T1000으로 확장한다. 모든 검증 후 카운터 증가, 실패 시 불변, 삭제 후 번호 미재사용을 유지한다.
2. 생성자 ID는 v3의 fullmatch 정규식을 따른다. C007·C0100·T0001처럼 불필요한 앞자리 0, 번호 0, 부족한 자릿수, 비ASCII 숫자를 거부한다.
3. `graph.id_sort_key(node_id)`를 공개했다. 종류 순서는 C<G<P<T, C/P/T 번호는 정수 순, G는 문자열 순이다. 키는 `(종류, 번호, 문자열)`이다. 무결성 진단의 비정상 문자열은 원문으로 결정적으로 정렬하며, 이 함수가 생성자 ID 검증을 대체하지 않는다.
4. 추천 점수·범위 확대·재고 규칙은 유지한다. 추천과 S4의 동점에서 P99가 P100보다 앞서며, 동료·지지자도 숫자 순이다.
5. A43(외부 검토 #20)의 한도 예외 문구 문제는 해당 한도·예외를 없애 해소했다. 계획서 반영 문안은 plan_pending.md 끝에만 추가했다.
